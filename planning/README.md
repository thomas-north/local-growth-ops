# Planning

Codex authors and executes plans here. Another coding agent is used only when
the user explicitly delegates work to it.

Use the newest numbered plan with unchecked required tasks unless instructed
otherwise.

Progress markers:

- `- [ ]` means not done.
- `- [x]` means completed.

The executing agent updates checkboxes as work is completed and adds short
execution notes when it must deviate from a plan.
